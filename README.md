## notes/ — الملاحظات اللاصقة

لوح ملاحظات لاصقة يعمل في المتصفح، ويمكن تثبيته على سطح المكتب كتطبيق (PWA)،
ويدعم فتح ملاحظة واحدة في نافذة عائمة تبقى فوق باقي النوافذ.
الملاحظات تُحفظ محليًا في المتصفح (localStorage) وتعمل دون اتصال بالإنترنت.

بدون أي اعتماديات — HTML/CSS/JS فقط، تُنشر مباشرة عبر GitHub Pages.

## sport/ — يلا رياضة

تنسيق مواعيد الرياضة مع صديق، بدل تبادل الرسائل في الواتساب حتى يتفق الطرفان.

كيف يعمل: تقترح نشاطًا ومكانًا وعدة أوقات، فيُنشئ التطبيق رابطًا واحدًا ترسله في
الواتساب. يفتحه صديقك ويضغط على الأوقات التي تناسبه ثم يعيد إرساله. الوقت الذي
يناسب الطرفين يظهر مميّزًا، وبضغطة واحدة يُؤكَّد ويُضاف إلى تقويم الهاتف مع تنبيه
قبل الموعد بساعة. بعد التمرين يُسجَّل ضمن سلسلة الأسابيع.

لا يوجد خادم ولا حساب ولا قاعدة بيانات: تفاصيل الخطة مضغوطة داخل الرابط نفسه
(نحو ٢٠٠ حرف)، وتُحفظ نسخة محليًا في المتصفح. عند فتح أي رابط تُدمج النسختان —
آخر تعديل يفوز للتفاصيل والحالة، ولكل شخص صوته المستقل — فلا يضيع رد أحدهما إن
ردّ الاثنان في وقت متقارب. ولأن لا شيء يُرسَل تلقائيًا، أي تغيير يحتاج إعادة إرسال
الرابط.

يعمل دون اتصال ويمكن تثبيته كتطبيق (PWA). بدون أي اعتماديات — HTML/CSS/JS فقط.
